# Getting help

- **Questions** about installing, configuring or reading results: [Discussions, Q&A](https://github.com/ratomirjovanovic/pandaward/discussions/categories/q-a). Search first; answered questions stay there for the next person. The [documentation](https://github.com/ratomirjovanovic/pandaward/wiki) and [Troubleshooting](https://github.com/ratomirjovanovic/pandaward/wiki/Troubleshooting) cover the common cases.
- **A wrong or missed finding**: run `pandaward feedback` or `/pandaward:feedback` in Claude Code. It files a report with rule metadata and counts only, no code, and every fix adds a benchmark case. See [docs/FEEDBACK.md](docs/FEEDBACK.md).
- **Ideas** for languages, frameworks, checks or workflow: [Discussions, Ideas](https://github.com/ratomirjovanovic/pandaward/discussions/categories/ideas), before an issue.
- **Bugs** in PandaWard: an [issue](https://github.com/ratomirjovanovic/pandaward/issues/new) with the version (`pandaward version`), the command and its output.
- **Vulnerabilities in PandaWard itself**: privately, through a [security advisory](https://github.com/ratomirjovanovic/pandaward/security/advisories/new). See [SECURITY.md](SECURITY.md).

Announcements of releases and of what changed in detection are posted in [Discussions, Announcements](https://github.com/ratomirjovanovic/pandaward/discussions/categories/announcements).
